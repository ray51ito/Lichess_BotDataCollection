# ボット・コードブック

> 英語版（主）: [README.md](README.md)

`bot_codebook.csv` は、2026年8月に人間とのレーティング対局が最も多かった80ボットのエンジン系統を人手でコーディングしたものである。これらのボットで人間対ボット対局の約96%を占める。各コードはLichessプロフィール（自己紹介と実名欄）に基づいており、根拠を `basis` 列に記録した。ここに載っているボットについては、コードブックのコードが `bots.classify_engine` のキーワード分類より優先される。

| 系統 | 定義 | 分析で使うグループ |
|---|---|---|
| `maia` | Maiaネットワーク（公式のmaia1/5/9、maia3モデル、HumaiaなどMaiaの重みを使うボット） | humanlike |
| `humanlike` | 人間の対局で学習した、または人間の指し方を模倣するよう明示的に設計された他のボット（dala、人間のミスモデルなど） | humanlike |
| `stockfish` | StockfishまたはFairy-Stockfish（レベルを下げたものを含む） | engine |
| `leela` | 従来型エンジンとして使われるLc0/Leelaネットワーク | engine |
| `homemade` | その他の探索型エンジン（自作または第三者製。Lynx、Demolito、GarboChessなど） | engine |
| `retro` | 歴史的または最小限のエンジンを浅い探索で再実装したもの（SARGON、TUROCHAMP、Bernstein、3615 DIAGO、μSunfish） | engine |
| `weak_novelty` | ギミック型または意図的にハンディを付けたボット（ランダムに指す、トリック狙い、クイーン捨て、チェックされるたびにEloが下がるなど） | other |
| `unknown` | 自己紹介にエンジンの記載がない | other |

コーディング規則:
1. 系統はボットが *表明している手法* で決める。名前だけでは決めない（ただし明示的に `maia` を名乗るものは除く）。
2. 指し方を規定するギミックは、基盤のエンジンより優先する。たとえばLeelaJesterは `leela` ではなく `weak_novelty` とする。
3. 「人間らしい」には、模倣の仕組みの記述（人間の対局で学習、人間のミスモデル）か、人間のように指すという明示的な主張が必要である。単に弱いだけでは該当しない。
